## 📖 About

This is the official church website for **Growing Missionaries Centre**, a ministry based in Isebania, Kenya. The site serves as a digital home for the GMC community — providing information about ministries, service times, church branches, community outreach programs, and ways to give.

The site reflects the church's core calling: **to love God and love people**, reaching them with grace, teaching them the truth, and sending them out on mission.

### Our Vision

> *"With one hand toward God and the other toward people, we commit ourselves to be used by God to Rescue, Recover, & Restore people who have never experienced the Presence and Power of God."*

---

## ✨ Features

- **Hero Section** — Full-screen video background with animated overlay
- **Responsive Navbar** — Fixed navigation with mega menu, dropdowns, and mobile hamburger menu
- **Ministries Overview** — Grid showcasing all 8 ministry departments (Children, Youth, Women, Men, Worship, Music, Prayer, Missions)
- **Sayuni Harvesters Choir** — Dedicated music ministry section with photo gallery
- **Branch Network** — Interactive photo mosaics for 8 regional church branches
- **Weekly Services Table** — Full schedule of weekly meetings and worship times
- **Community Impact** — Highlights of education support, environmental care, and widows/orphans outreach
- **Giving Section** — Bank transfer and mobile money (M-Pesa) payment details
- **Contact Form** — In-page form that opens the user's email client
- **Scroll Animations** — Smooth fade-in reveal as users scroll (respects `prefers-reduced-motion`)
- **Back to Top** — Floating button for quick navigation
- **SEO & Accessibility** — Semantic HTML, `aria-*` attributes, skip-to-content link, Open Graph meta tags, JSON-LD schema
- **Performance** — Lazy-loaded images, passive scroll handlers, CSS `content-visibility` friendly layout

## 🚀 Getting Started

This is a **static HTML/CSS/JS website** — no build tools or frameworks required.

### To run locally:

1. **Clone the repository** or download the files.
2. **Open `index.html`** in any modern web browser.

```bash
# Example: serve locally with Python
python -m http.server 8000
# Then visit http://localhost:8000
```

> **Note:** Some features (video backgrounds, Google Fonts, Font Awesome icons) require an internet connection.
